スライドの編集画面でこの枠を開き、表示する内容を設定してください。

HTML Frame

埋め込みを禁止しているサイト（Google 検索、GitHub など）は表示されません。YouTube は https://www.youtube.com/embed/動画ID の形で入れます。http のページは表示されないことがあります。

表示の設定

0 なら枠の大きさのまま表示します。幅を入れると、その幅で描いた画面を枠に合わせて拡大縮小するので、編集画面とスライドショーで見た目がそろいます。

スライドショーで動きが重いときに下げます。小さくするほど軽くなり、表示は粗くなります。キャンバスや WebGL の大きさを devicePixelRatio で決めている HTML に効きます。この画面の倍率は今 倍です。

枠の左上に 1 秒あたりの描画回数を出します。解像度の設定の効き目を確かめるときに使います。描画の解像度と FPS の表示は「HTML を書く」のときだけ効きます。

「HTML を書く」のときだけ効きます。HTML の中のスクリプトがアドイン本体に触れられるようになるので、自分で書いたコードのときだけ有効にしてください。
